# Novel Logs

Session records for The Experimental Novel. Every work session on the novels —
development, research, writing — gets one file here, in the first person, on
the public record.

## Spec

Format follows [novel-log-spec_v1.0.md](novel-log-spec_v1.0.md) (inherited from
the studio-log spec): one file per session, named `YYYY-MM-DD-HHMM-<slug>.md`
(24h local time), YAML frontmatter, fixed section order. `Decisions` and `Next
actions` are mandatory — a session with no decisions recorded is a session not
yet understood. Voice is "I," never "he." No personal material: the novels are
not about the author.

## The pipeline

The novel log is the first stage: what the log records gets backed up by the
theory (`../theory/`) and lands in the novels folders (`../novels/`) — it
trickles through the folder structure.

## Session types

- `discourse` — development sessions (the usual case here)
- `research` — text-engine work, source verifications, reference work
- `studio` — writing sessions (drafting, dictation, revision)
- `admin` — operational sessions (releases, uploads, scaffolding)

## How to add a log

Say **"log this session"** (or "add a novel log") and describe what was done,
decided, hit, and made. Reconstructed entries carry a reconstruction line with
date and sources — never backfilled silently.
